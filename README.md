# Nexus Admin Dashboard

A modern, responsive SaaS-style admin dashboard built with React, Vite, Tailwind CSS, React Router, Lucide React and Recharts.

## Included pages
- Dashboard
- Users
- Orders
- Analytics
- Notifications
- Settings

## Mandatory task features covered
- Responsive sidebar with mobile drawer
- Top navigation
- Dashboard statistic cards
- Recent orders/activity table
- User/profile card
- Notifications center
- Search bars and filters
- Revenue and user-growth charts
- Light animations and hover states
- Fully responsive layout
- Reusable React components
- Functional React hooks/state
- Organized scalable folder structure

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

No backend is required; the project uses mock data.
